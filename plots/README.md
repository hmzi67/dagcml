## Plots

Training and evaluation scripts export figures (PNG, PDF, interactive HTML) into this folder. Typical artifacts include:
- Curriculum difficulty histograms and sliding-window views.
- Learning curves for warm-up, meta-episodes, and zero-shot evaluation.
- Confusion matrices or per-language accuracy charts.

Because these files can be large or binary, the `.gitignore` rules exclude everything except this README. Commit only curated visualizations that are necessary for documentation.
